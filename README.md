# 🎓 Marks & Grade Calculator

A simple command-line program that calculates total marks, percentage, grade and pass/fail result for a student.

## Features
- Works for any number of subjects
- Validates input (no negative marks, no marks above the maximum, no text)
- Prints a neat report card
- Pass/fail rule: at least 40% overall and 33% in every subject

## Tools Used
- Python 3 (no extra libraries needed)

## How to Run
```bash
python grade_calculator.py
```

## Sample Output
```
--- Report Card ---
Name: Moyuri
Maths                 85.0/100
Python                92.0/100
Statistics            78.0/100
Total: 255.0/300
Percentage: 85.00%
Grade: A
Result: PASS
```
